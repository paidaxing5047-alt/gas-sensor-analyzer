# 气体传感器数据分析软件 🧪

> **你不需要复制粘贴任何代码！** 所有代码已经在这个仓库里了。
> 按照下面的步骤，**3 分钟**即可在本地运行。

---

## ✅ 快速开始（3 步）

### 第 1 步：把代码下载到本地

在 VSCode 终端（或系统终端）中运行：

```bash
git clone https://github.com/paidaxing5047-alt/gas-sensor-analyzer.git
cd gas-sensor-analyzer
```

> 如果你已经克隆过这个仓库，只需在项目文件夹里运行 `git pull` 拉取最新代码即可。

---

### 第 2 步：安装依赖包（只需做一次）

```bash
pip install -r requirements.txt
```

等待安装完成，看到 `Successfully installed ...` 即可。

---

### 第 3 步：启动程序

```bash
python main.py
```

你会看到：

```
============================================================
🧪 气体传感器数据分析软件 v1.0
============================================================
🌐 访问: http://localhost:5000
📁 上传Excel文件开始分析
============================================================
```

然后**打开浏览器**，访问 👉 **http://localhost:5000**

---

## 📖 使用说明

1. **上传 Excel 文件** — 把你的测量数据文件（`.xlsx`）拖放到上传区域
2. **查看结果** — 自动计算 9 项指标并显示在表格中
3. **切换图表** — 点击标签页查看响应曲线、灵敏度、选择性等 6 种图表
4. **导出数据** — 点击按钮下载 CSV 数据表或分析报告

### Excel 文件格式要求

工作表名称必须为 **`测量数据`**，表头格式如下：

| 材料 | 测试气体 | 气体浓度(ppm) | 测试温度(°C) | 测试湿度(%) | 加入气体时刻(s) | 排出气体时刻(s) | 0s | 1s | 2s | … | 300s |
|------|---------|--------------|------------|-----------|-------------|-------------|-----|-----|-----|---|------|
| M001 | NH3     | 100          | 25         | 45        | 50          | 200         | 5000 | 5010 | … | … | 5100 |

> 时间列（`0s`、`1s`、…、`Ns`）长度可变，软件会自动识别。

## 🧮 自动计算的指标

| 指标 | 说明 |
|------|------|
| 基线电阻 (Ω) | 注入气体前的平均阻值 |
| 响应电阻 (Ω) | 气体作用期间的极值电阻 |
| 响应值 (%) | (响应电阻 − 基线) / 基线 × 100 |
| 响应时间 (s) | 达到 90% 响应量所需时间 |
| 恢复时间 (s) | 排出气体后恢复到 90% 基线的时间 |
| 响应速率 (%/s) | 响应值 / 响应时间 |
| 恢复速率 (%/s) | 响应值 / 恢复时间 |
| 稳定性 (方差) | 响应平台期的波动程度 |
| 灵敏度 (%/ppm) | 响应值 / 气体浓度 |

## ❓ 常见问题

**Q: 安装依赖时报错怎么办？**
```bash
pip install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple/
```
（使用国内镜像源，速度更快）

**Q: 端口 5000 被占用怎么办？**

修改 `main.py` 最后一行的 `port=5000` 改为其他端口，如 `port=8080`，然后访问 http://localhost:8080。

**Q: 想用示例数据测试？**

上传 `sample_data/sample.xlsx` 文件即可，里面已包含 6 条模拟测量数据。
